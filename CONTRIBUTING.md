# Contributing

Use a focused branch and include tests and documentation for behavior changes. Keep input-schema indices append-only, preserve compatibility records, and run the relevant build and tests before opening a pull request.

Do not commit game binaries, copied reference assemblies, build output, `.obj`, `.bin`, or user logs. Use each adapter's checked-in reference-preparation script for local development.

By contributing, you agree that your contribution is licensed under the repository's Apache License 2.0 terms.
