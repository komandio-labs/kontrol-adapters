Official game adapter library

Connect the controls you already own to the games you play.

Kontrol is a Windows app for using joysticks, throttles, button boxes, wheels, pedals, and custom controllers with supported games. Each adapter understands one game’s native input model, so your hardware can work with the game instead of pretending to be a keyboard.

How the pieces fit together

One Kontrol app, one active game context, one adapter for that game.

Kontrol reads your connected devices and applies your profile. The selected game adapter translates that input into the actions understood by the game. The library below keeps each game’s current release easy to find while preserving older versions for troubleshooting and compatibility history.

Signed packages

Every ZIP has a publisher signature and SHA-256 hash so Kontrol can verify the exact bytes before installing.

Windows desktop

Kontrol is a Windows desktop app. These adapters are distributed for the Windows host and its supported games.

Game-version aware

Adapter compatibility is tied to the game builds that were actually checked, not a vague version range.
