# Security policy

Do not report security-sensitive issues in a public GitHub issue.

For this public repository, use GitHub's **Report a vulnerability** form on the
repository's **Security** tab. That form creates a private report visible only
to the reporter and repository security maintainers. It is the preferred route
for issues involving package signing, the catalog, process injection, IPC,
local file modification, or privilege boundaries.

If the form is temporarily unavailable, contact the Komandio Labs maintainers
through the organization profile and request a private reporting channel. Do
not include exploit details in a public issue.

Include the affected adapter, adapter version, game version, reproduction
steps, impact, and any safe proof of concept. Please allow reasonable time for
triage and a fix before public disclosure.
